# Иконка KnotHop: брецель (pretzel) и встраивание

Черновик иконки Android-приложения. Все выходы генерирует `tools/gen.py` из одной геометрии.
Пересборка: `python3 design/icon/tools/gen.py` (нужны Pillow и `rsvg-convert`, сети не нужно).
Прежние A/B/C (восьмёрка, трилистник, первый крендель) лежат в `old/`.

## Форма

Силуэт по фото брецеля:
- сверху две округлые доли (левая и правая), между ними неглубокая впадина;
- внутри над скруткой маленькое треугольное отверстие;
- скрутка одна, в верхней-средней части: две ножки перекрещиваются с разрывом over/under;
- ножки ложатся поверх живота, их концы выступают наружу за нижний край;
- живот — широкая нижняя дуга, на 2 единицы толще теста;
- два больших каплевидных отверстия по бокам между долями и ножками.

Ширина больше высоты (около 1.1:1: примерно 59 на 53 единицы). Тесто 9 единиц, живот 11.5, края скруглены (линии с
круглыми концами). Все контрольные точки заданы явно в `tools/gen.py` (`A_PTS`, `BELLY_PTS`,
`DIP_PTS`, `X_HUB`); правая половина — зеркало левой.

## Ноды

Ноды одинаковые, бирюзовые (`#34D399`), радиус 2.6, пять штук: два плеча, два конца ножек
(вход и выход) и середина живота. Узлов на скрутке нет, хаба нет.

## Варианты

Холст 108×108, фон `#0D2538`, тесто `#D98B3A`, живот `#A35A22`.

- **A · Узлы без маршрута** (`pretzel-a.svg`): пять нод на тесте, без линии. Самый спокойный.
- **B · Маршрут вход → живот → выход** (`pretzel-b.svg`): то же, и тонкая линия (1.8)
  соединяет левый конец ножки, точку на животе и правый конец ножки. **Рекомендую.**
- **C · Маршрут по контуру** (`pretzel-c.svg`): то же, и линия идёт по внешнему контуру
  через обе доли и впадину, от одного конца ножки к другому. Больше «сетевости», но линия
  сливается с краем теста.

## Проверки и ограничения

- Безопасная зона adaptive icon (диаметр 66): наибольший радиус 31.65 при пределе 33.
  `gen.py` падает, если предел превышен.
- Монохром (`mono-*`): ноды и маршрут в него не входят, это только тесто и живот. Силуэт
  читается как брецель по долям и боковым отверстиям. Риск: центральная скрутка в
  монохроме похожа на крест, поэтому при 48 px силуэт может читаться слабее цветного.
  Если на телефоне монохром будет похож на крест или «запрет», нужно укрупнить боковые
  отверстия (уменьшить тесто) или убрать перекрест.
- Треугольное отверстие над скруткой маленькое: в 192 и 512 px видно, в 48 px почти
  сливается. Это ограничение формы при сохранении скрутки и safe-зоны.
- **Не проверено на устройстве**: Android SDK здесь нет. Рендер в launcher, круглая маска и
  тема Android 13 (monochrome) не проверялись.

## Файлы

- `pretzel-a.svg`, `pretzel-b.svg`, `pretzel-c.svg`: полные иконки (фон + передний план).
- `preview-sheet-pretzel.png`: все варианты (512, 192, 48, круг 192, монохром 192/48).
- `previews/pretzel-{a,b,c}-{512,192,48,circle-192,mono-192,mono-48}.png`.
- `android-res/`: ресурсы для рекомендованного варианта (B):
  - `drawable/ic_launcher_foreground.xml`: передний план (тесто, живот, ноды, маршрут),
    11 путей, совпадают с `pretzel-b.svg` побайтно.
  - `drawable/ic_launcher_background.xml`: фон, сплошной `#0D2538`.
  - `drawable/ic_launcher_monochrome.xml`: монохром из теста и живота, 5 путей.
  - `mipmap-anydpi-v26/ic_launcher.xml` и `ic_launcher_round.xml`: adaptive-icon.
  - `mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png` и `ic_launcher_round.png`:
    legacy PNG 48/72/96/144/192. При `minSdkVersion="26"` не используются.
- `tools/gen.py`: генератор. `RECOMMENDED = "b"` выбирает вариант для `android-res/`.
- `old/`: прежние A/B/C и `old/README-abc.md`. `old/tools/gen-abc.py` работает внутри `old/`.

## Встраивание (ничего не скопировано)

Сейчас в `bench/android/vpn/` нет `res/` и нет `android:icon` в манифесте.

1. Скопировать в `bench/android/vpn/res/`:
   - `android-res/drawable/*.xml` → `bench/android/vpn/res/drawable/`
   - `android-res/mipmap-anydpi-v26/*.xml` → `bench/android/vpn/res/mipmap-anydpi-v26/`
   - при необходимости `android-res/mipmap-<плотность>/*.png` → `bench/android/vpn/res/mipmap-<плотность>/`
     (каталоги создаются при копировании).
2. В `bench/android/vpn/AndroidManifest.xml` в элемент `<application ...>` добавить атрибуты:
   `android:icon="@mipmap/ic_launcher" android:roundIcon="@mipmap/ic_launcher_round"`.
3. В `bench/android/build.sh` сейчас `aapt2 link` вызывается без скомпилированных
   ресурсов, поэтому иконка в APK не попадёт. Нужен шаг компиляции перед линковкой, например:
   ```sh
   "$BT/aapt2" compile --dir "$SRC/res" -o "$W/res.zip"
   "$BT/aapt2" link -o "$W/base.apk" -I "$PLATFORM" --manifest "$SRC/AndroidManifest.xml" \
       "$W/res.zip" --min-sdk-version $API --target-sdk-version 34
   ```
   Шаг нужен только для `vpn`; `build.sh` не менялся.
4. Проверка после сборки: `aapt2 dump badging base.apk | grep -i icon` должен показать
   иконку приложения, и она должна появиться на экране телефона.

Метка приложения в манифесте по-прежнему `android:label="rawg VPN"`. Это не часть задачи
иконки и не менялось.
