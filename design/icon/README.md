# KnotHop: пекарный брецель

Самостоятельный векторный рисунок по форме и цвету предоставленных фотографий.
Фотографии не копировались в репозиторий. Никаких сетевых элементов в рисунке нет.
Все изменения ограничены `design/icon/`; приложение и сборочные скрипты не изменены.

## Результат

- `bretzel.svg` — основной вариант, тёмно-синий фон `#0D2538`.
- `bretzel-cream.svg` — тот же рисунок на кремовом фоне `#F5E6CA`.
- `bretzel-foreground.svg` — прозрачный передний план.
- `bretzel-monochrome.svg` — белый силуэт с тремя отверстиями, без соли.
- **`preview-sheet-bretzel.png`** — сравнение двух фонов, круглых масок и монохрома.
- `previews/bretzel-*` — рендеры 512, 192 и 48 px, в том числе круглые;
  `bretzel-iteration-{1,2,3}.png` — просмотренные промежуточные варианты.
- `android-res/` — готовый набор ресурсов, основной фон тёмно-синий.
- `old/previous-pretzel/` — перенесённые прежние попытки, их генератор и README.
  Остальной существовавший архив `old/` сохранён.

## Геометрия и проверки

Одна непрерывная центральная линия жгута: левый конец → скрутка → левая доля →
нижняя дуга → правая доля → скрутка → правый конец. Локальные верхние слои
показывают перекрытия; под ними лежат контактные тени. Левая доля выше правой.
Тёмный край, линейные градиенты, продольные блики и 30 неправильных кристаллов
соли формируют объём. SVG не использует фильтры, шрифты и растровые вставки.

Три просмотренные итерации: начальная геометрия; устранение стыков нижней дуги
и добавление соли; усиление объёма и нерегулярности соли. После проверки 48 px
нижняя дуга дополнительно опущена: маленькое отверстие больше не распадается.

Холст 108×108, масштаб жгута 0.91 относительно центра (54,54). Проверенный
радиус цветного переднего плана **32.73 при допустимом 33**: safe-круг Ø66
почти заполнен, рисунок не выходит за него. Поля на полном холсте намеренны:
это безопасная геометрия adaptive icon, не попытка заполнить все 108 единиц.

Проверено локально:

- XML разобран стандартным XML-парсером;
- **`aapt2 compile` и `aapt2 link` прошли** (build-tools 35.0.0, android-36);
  временный тестовый APK удалён;
- монохром содержит ровно три раздельных отверстия и при 512, и при 48 px
  (в 48 px площади отверстий: 8, 46 и 50 пикселей при пороге alpha 128);
- просмотрены PNG всех трёх итераций, включая цветные 48 px и монохром.

Ограничения: на реальном Android-launcher не проверено; при 48 px соль и тонкие
блики естественно упрощаются. Монохром не передаёт over/under и объём.
Legacy PNG оставлены в той же безопасной геометрии и поэтому выглядят компактнее
полноформатных legacy-иконок. На листе рендер 512 px показан уменьшенным до 430 px;
отдельный файл `previews/bretzel-navy-512.png` имеет настоящий размер 512×512.

## Воспроизведение без сети

Из корня репозитория (Python 3, Pillow, `rsvg-convert`):

```sh
python3 design/icon/tools/generate_bretzel.py
python3 design/icon/tools/validate_bretzel.py
```

Генератор по умолчанию создаёт итоговую третью итерацию. Проверка использует
`ANDROID_HOME` или `~/Android/Sdk`; если SDK недоступен, явно сообщает, что
компиляция aapt2 пропущена. Исходная геометрия и палитра — в генераторе;
VectorDrawable строится из тех же путей и градиентов, что SVG.

## Android-ресурсы

- `drawable/ic_launcher_foreground.xml`: VectorDrawable, 80 путей, градиенты
  через `aapt:attr` (в том числе `android:strokeColor`); viewport 108×108.
- `drawable/ic_launcher_background.xml`: основной однотонный фон.
- `drawable/ic_launcher_background_cream.xml`: альтернативный фон.
- `drawable/ic_launcher_monochrome.xml`: три белых пути, объединяющихся в силуэт.
- `mipmap-anydpi-v26/ic_launcher{,_round}.xml`: adaptive icon для API 26+.
- `mipmap-anydpi-v33/ic_launcher{,_round}.xml`: дополнительно `monochrome`
  для themed icon Android 13+. В v26 этот элемент намеренно отсутствует.
- `mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher{,_round}.png`:
  legacy PNG 48/72/96/144/192 px, у round прозрачные углы.

Для кремового варианта заменить ссылку `@drawable/ic_launcher_background`
на `@drawable/ic_launcher_background_cream` в четырёх adaptive XML.
Legacy PNG при этом нужно отдельно перегенерировать с выбранным фоном.

## Как встроить (не выполнено)

1. Скопировать содержимое `android-res/` в `bench/android/vpn/res/`, сохранив
   все квалификаторы, включая `mipmap-anydpi-v33`.
2. В `<application>` файла `bench/android/vpn/AndroidManifest.xml` добавить:

   ```xml
   android:icon="@mipmap/ic_launcher"
   android:roundIcon="@mipmap/ic_launcher_round"
   ```

3. `bench/android/build.sh` пока не компилирует ресурсы. Перед существующим
   `aapt2 link` нужен шаг, а архив ресурсов нужно передать линковщику:

   ```sh
   "$BT/aapt2" compile --dir "$SRC/res" -o "$W/res.zip"
   "$BT/aapt2" link -o "$W/base.apk" -I "$PLATFORM" \
       --manifest "$SRC/AndroidManifest.xml" "$W/res.zip" \
       --min-sdk-version "$API" --target-sdk-version 34
   ```

   Сохранить остальные существующие аргументы линковки. Для элемента `monochrome`
   нужен compile SDK/platform API 33 или выше; target SDK менять ради него не нужно.
4. После сборки проверить `aapt2 dump badging` и реальный launcher: обычную,
   круглую и themed-иконку. `build.sh` и манифест в рамках этой работы не менялись.
